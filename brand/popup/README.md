# PopUp branding assets

Brand kit used by the Recreate agent for end cards, captions and UI callouts. Details and sources are in `brand.json`.

- `app-icon-1024.jpg`: the App Store icon, an iridescent bubble on a violet gradient.
- `fonts/Montserrat[wght].ttf`: the typeface the official website uses (SIL OFL).
- `reference/`: App Store screenshots showing the in-app style.

These come from public sources, not an official brand kit. Replace them when official files are available.
